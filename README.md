This repository contains the complete Dart source code for the Limkokwing Student Results Management System (LSRMS) console prototype. The project demonstrates core software engineering principles for managing student records, recording academic marks, validating inputs, and automatically computing grades based on the university's approved grading scale. The repository includes the main source code files, step-by-step setup instructions for running the program via the Dart SDK, and sample execution logs demonstrating student registration and result retrieval.
